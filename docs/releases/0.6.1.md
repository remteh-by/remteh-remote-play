# Deckivo 0.6.1 preview

An experimental update for your own PS5: Switch OLED running Android, Android
ARM64, Apple Silicon Mac, and a Switchroot Ubuntu ARM64 developer preview.
Built on Chiaki, chiaki-ng and Android Extended; their history and attribution remain.

## English

- Shared funding configuration: the existing Ko-fi profile, large locally generated QR codes, positive support copy and real development goals. Empty wallet/Boosty fields and an empty supporters list stay hidden.
- A gentle thank-you after a clean user-ended session of at least 10 minutes; Later waits 14 days, maximum three displays; Never stops it. No popup during streaming.
- Android updater messages use resources in 16 languages. Browser-less devices get a QR fallback. Offline dependency licenses and exact-version source link are built in.
- Desktop RSA PKCS#1 v1.5 SHA-256 verification no longer executes openssl. Both native platforms wait up to 120 seconds for startup confirmation; a failed live child is stopped before rollback.
- One native build number: Mac/Linux 10, Android code 25. Registration/signing identities stay the same.
- A static website in 16 languages, localized SEO/FAQ, mobile test cards, a WOFF2 subset and real UI artwork. Sony press media removed. Analytics and the future custom domain remain off.
- Android Lint: 0 errors and 0 warnings outside the **96 unchanged upstream warnings in baseline**. The historical 249 warnings were 85 new Deckivo + 68 modified-file + 96 upstream, not all pre-existing.
- CycloneDX inventories for the resolved Android graph and this Mac build's Python runtime accompany the release.

Validation before packaging: 31 Android unit tests, 38 native/Qt tests; four
funding-config checks, eight host helper protocol tests and the decoder lifecycle
harness (100 cycles, ASan/UBSan). Site: 24 responsive cases (en/ru/ar/ja,
390–3840px), 16 language pages without JS, no horizontal overflow or broken images.
The host helper rejection tests explicitly allow macOS TCP reset before headers
for malformed requests; valid responses still require a complete JSON body.

Physical OTA acceptance is recorded separately in `docs/TESTED.md` and
`0.6.1-public-channel-validation.json` after the public packages are available.
A built/signed release is not itself proof of installed-device behavior.

Not certified: Ubuntu 0.6.1 on hardware while the Switch runs Android; the real
six-hour update timer; a real 10-minute reminder/14-day wait; sustained gameplay,
Internet/VPN play, every controller feature, notarization or donation payments.
Windows and Intel Mac builds are not offered in this preview.

## Русский

- Одна конфигурация поддержки: существующий Ko-fi, крупные QR без сети и понятные цели. Пустые кошельки, Boosty и список спонсоров не отображаются; собранные суммы не выдуманы.
- Благодарность после штатно завершённого пользователем сеанса от 10 минут. «Позже» — минимум через 14 дней, всего до трёх показов; «Не показывать» отключает карточку. Во время трансляции её нет.
- Переведены статусы Android-обновления, добавлены QR при отсутствии браузера, офлайн-лицензии и ссылка на исходники именно этого выпуска.
- На desktop подпись RSA проверяется на Python без внешнего openssl. Mac и Linux ждут подтверждения старта до 120 секунд, останавливают новую версию перед восстановлением старой.
- Номера: Android 25, Mac и Linux 10. Идентификаторы, ключи подписи и регистрация сохраняются.
- Сайт: 16 готовых языковых страниц без зависимости от JS, SEO/FAQ, таблица-карточки на телефоне, WOFF2 и настоящие изображения интерфейса вместо пресс-фото Sony. Аналитика и новый домен выключены.
- Lint: 0 ошибок и 0 предупреждений вне baseline из 96 замечаний неизменённого upstream. В старых 249 было 153 замечания в наших новых/изменённых файлах.
- К выпуску приложены CycloneDX SBOM и SHA-256.

Пройдены 31 Android- и 38 desktop-тестов; дополнительные проверки конфигурации,
локального помощника и декодера; 24 проверки ширины сайта до 4K и все 16 языков
без JS. Приёмка публичного OTA на устройствах фиксируется отдельно после публикации.

Ubuntu 0.6.1 на железе, длительная игра, интернет/VPN, реальный таймер обновлений,
долгие таймеры благодарности и получение донатов остаются отдельными тестами.
Mac пока с ad-hoc подписью, без нотарификации. Прошивку PS5 этот выпуск не меняет.
