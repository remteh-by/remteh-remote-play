# Deckivo 0.8.7 preview · Android 32 / desktop 23

Published on 2026-10-30 at the owner's explicit request to proceed without physical-device checks. The 0.8.7 release and signed updater metadata are public. Installation on a device is not claimed; old release assets remain unchanged.

## Changes / Изменения

Android update checks retain the server retry deadline after a backward clock change, rebase it once, and keep manual checks within the same embargo. Shared desktop input ownership, stopping and live configuration fixes from the reviewed local branch are included. A connection check reports only observed facts: saved registration, recent discovery response, selected profile, available engine, engine-reported video frames and input. Unknown conditions remain unknown; it does not guess a VPN fault.

Linux installation gains read-only preflight for the supported Switchroot Ubuntu ARM64 environment. Existing installations are directed to the upgrade procedure, preserving pairing and settings. macOS packaging supports isolated staging and runtime selection. Signing tools require the existing signing identity instead of silently creating a replacement.

На сайте версия скачивания берётся из проверенного опубликованного релиза. Предварительный выпуск 0.8.7 опубликован отдельно; прежняя 0.8.6 сохранена. Публикация Pages проходит собственную проверку пакетов и браузерные сценарии того же коммита.

## Validation

- 130 desktop unit regressions, including session lifecycle, input ownership, update verification, preflight and connection snapshot privacy.
- Android release compilation, release lint and 49 unit tests. APK signed using the existing certificate; fingerprint compared with public 0.8.6.
- 112 rendered site combinations and 16 no-JavaScript language pages; Controller Lab synthetic-state tests. These checks do not establish physical controller behavior.
- macOS staging and package checks are recorded separately in the external candidate manifest.

## Pending acceptance / Непроверенное

The owner authorized publication without device checks; these scenarios remain unverified. Test Android installation over 0.8.6, locale/update failure and retry on-device; Switch Ubuntu install/update/reboot and hardware decoding; macOS real PS5 video, audio while unfocused, WASD/mouse, controller ownership, minimize/restore/maximize and complete engine exit. Test USB/Bluetooth controllers, sleep/reconnect and sustained play independently. A passing test suite is not a substitute.

The Mac candidate is ad-hoc signed, not notarized. No Intel or generic Linux compatibility is claimed. The download site uses a fresh real Qt capture of 0.8.7 build 23 with empty isolated profile data. Keep exact source SHA, package hashes, validation report and all license/source notices together.

## Install / update / rollback

Follow BUILDING.md, docs/LINUX.md and docs/PLATFORMS.md. The public Android manifest and RSA-signed desktop feed offer the published preview with the existing identities and integrity checks. Preserve the working installation and private registration before an owner device test; use the existing authenticated updater/rollback path when promoting a verified release. Do not uninstall Android to bypass a certificate mismatch or switch signing keys.
