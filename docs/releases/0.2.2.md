# Deckivo 0.2.2 — одна карточка сохранённой консоли и её сетевого обнаружения

Android versionCode 14. Локальная версия, установка поверх 0.2.1 сохраняет регистрацию и настройки.

Раньше список без сопоставления складывал результаты сетевого поиска и ручные адреса. Поэтому одна PS5 появлялась дважды. Теперь известная консоль сопоставляется по аппаратному идентификатору и выбранной регистрации: карточка показывает сетевой статус и сохраняет закладку ручного адреса для редактирования. При выключенном поиске остаётся сохранённая карточка. Записи в базе не удаляются и не мигрируют.

Различные консоли с одинаковыми именами, известные разные аппаратные идентификаторы и отдельные пользовательские регистрации сохраняются отдельно. Повторные ответы обнаружения одного устройства объединяются; готовый к подключению ответ предпочтительнее состояния покоя. Для неизвестных устройств не используются имена как идентификатор.

Восемь регрессионных проверок в DisplayHostMergerTest дополняют существующие проверки языка, обновлений и локальной настройки. Фактические результаты APK и Switch приведены в 0.2.2-validation.json. Частные снимки экрана и журналы в исходники не включаются.

Исправление чёрного экрана при повторном подключении из 0.2.1 включено. Публикация новых исходников, APK и сайта остаётся отложенной до завершённой 1.0.0 и проверки владельцем.
