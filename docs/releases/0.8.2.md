# Deckivo 0.8.2 · project links and clearer downloads

Android build **27**, macOS Apple Silicon build **18**, and Switchroot Ubuntu
ARM64 build **18** add visible links to the project on GitHub and to RemTeh.by.
The website puts device selection and downloads first, explains what each
package is for, and keeps setup and technical details nearby.

RemTeh links use UTM source labels for Android, macOS, Ubuntu, GitHub and the
Deckivo website. These parameters are sent only when a link is opened; they do
not contain an account identifier or a device identifier. Ko-fi remains the
existing [RemTeh profile](https://ko-fi.com/pavelzayats).

The Ubuntu background updater from 0.8.1 is retained. Signed desktop packages
and the existing Android application certificate preserve the update path and
console registration. Updates wait while a Remote Play session is active.

## Checks at packaging

- 74 desktop/package tests and 37 Android release tests passed.
- Android release assembly and lint passed, with 96 existing baseline entries
  and no new lint findings. The APK keeps the existing signing certificate,
  package `by.remteh.remoteplay`, minimum Android 8 and ARM64 architecture.
- The Mac ARM64 application built successfully and passed ad-hoc codesign
  verification. Developer ID signing and notarization are not claimed.
- Physical update results and website viewport checks are recorded separately
  after publication. Android 0.8.2 has not been installed on the test Switch,
  which is currently running Ubuntu. Build success is not gameplay acceptance.

Choose the package for the device displaying your PS5 stream. New Ubuntu
installations require the runtime setup in [the Linux guide](../LINUX.md);
the small Linux upgrade ZIP is for an existing Deckivo installation.
