# Deckivo 0.8.12 Android audio preview

Android 0.8.12 / build 37 reduces avoidable buffering in the Remote Play audio output. It declares game audio usage, starts the output queue at two Oboe bursts, and uses Oboe's latency tuner to increase that queue when underruns require it. Opening an unavailable audio output now returns safely instead of dereferencing a missing stream.

A reversible device comparison on a Switch OLED running Android 15 with Galaxy Buds Live (AAC) reduced the client buffer from 19,006 to 1,920 frames at 48 kHz, approximately 396 to 40 ms. The reported AudioTrack latency changed from about 850 to 477–488 ms. These are Android buffer/track estimates, not measured acoustic or end-to-end latency. The Bluetooth output still reported roughly 390 ms of its own buffering; zero-delay Bluetooth playback is not claimed. Auditory confirmation and broad headset testing remain pending.

The final 0.8.12 device session decoded 9,443 frames at an average 59.94 decoded frames/s, with zero receiver-lost frames in that sample. Presented/display FPS was not measured.

The same device was moved from its saved 2.4 GHz Wi-Fi connection to the available 5 GHz band and set to H.264, 720p/60 and 8 Mbit/s. A 10-packet PS5 ping sample averaged 6.8 ms with no loss. A separate near-five-minute 0.8.11 session decoded an average 59.3 frames/s; this is not presented/display FPS. The PS5 game displayed a disconnected-controller notice, so sustained gameplay and physical controller acceptance are not established by this check.

The Android package ID, signing certificate, existing PS5 registration, optional Ko-fi support and update trust policy remain the same. The release is Android-only; desktop packages remain at 0.8.11 / build 27. No desktop audio change is included.

Validation: native arm64 release build, 49 Android unit tests and Android lint completed. Lint retains two existing warnings plus its existing baseline. Exact package hashes and final-version device readback are recorded separately in 0.8.12-validation.json.
