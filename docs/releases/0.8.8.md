# Deckivo 0.8.8 — support methods

Experimental prerelease. Android versionCode 33; macOS and Switchroot Ubuntu build 24.

The support screen now lists Ko-fi, Patreon, Afdian, Boosty, DonationAlerts, DonatePay and the owner-provided OKX Pay receiving link. Select a provider, open its external page, copy its exact link or scan its QR. The desktop and Android apps remember the selection locally. The website, README and 16 guides use the same generated registry.

Each destination shows its actual setup status and support cadence. Afdian approval is pending; Boosty is a prepared creator profile with paid tiers awaiting verification. Other configured or untested destinations do not imply a successful payment. OKX Pay requires the OKX app and is not an automatic subscription. No referral link or unverified blockchain-token destination is used.

All support is optional. No payment is processed by Deckivo, no private account login data is distributed, and contributions do not buy individual support, commissioned work or release deadlines. Upstream credits and the upstream author's separate funding link remain intact.

## Validation

Automated checks and exact artifact hashes are recorded in the attached 0.8.8-validation.json and SHA256SUMS.txt. IDs, Android certificate and desktop RSA update key are preserved. The public signed feeds distribute the exact released APK, Mac bundle and Switchroot Ubuntu source update.

Physical Android / Ubuntu interaction on Switch, long Remote Play sessions, gamepad input and fresh-user Gatekeeper acceptance require the devices and are not established by a successful build. Actual payment receipt, renewals and withdrawal verification remain separate provider checks.
