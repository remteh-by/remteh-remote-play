# Deckivo 0.8.1 · Switchroot Ubuntu updater fix

Linux build **17** repairs automatic delivery for an existing Switch OLED /
Switchroot Ubuntu 24.04 ARM64 installation. Public Android and macOS binaries
remain **0.6.1**; this release does not provide a new APK or Mac application.

The public Linux feed previously offered 0.6.1 build 10, so an installed build 10
correctly reported no update. A separate packaging defect omitted `upgrade.py`
from installed files, which could stop an update before relaunch. Both are fixed.

With automatic updates enabled, a systemd user timer checks shortly after login
and approximately every two minutes while Ubuntu is awake. It can stage signed
updates with Deckivo closed. The next idle dashboard installs the staged update;
streaming is never interrupted, and no hidden application window is started.
Temporary network failures retry; verified staged downloads remain usable offline.

The updater verifies the pinned RSA signature, exact size and SHA-256, platform,
version and build. Metadata/packages are immutable in the cache, and a shared
lock prevents GUI/background races. Startup acknowledgment and rollback remain
in place. Registration, preferences and the existing streaming runtime are kept.

The upgrade includes the shared controller lab and keyboard/mouse bindings from
the 0.7/0.8 development line. Physical testing of every controller and sustained
gameplay is still separate from successful updater delivery.

## Validation at packaging

- 74 desktop/package tests passed on the build Mac.
- Both native adapters compiled on the physical Switch OLED / Ubuntu 24.04.4
  ARM64 with `-Wall -Wextra -Werror`.
- The update ZIP contains 94 unique paths, including 80 installer files and 14
  license/attribution documents; the helper appears exactly once.
- Public-device update acceptance is recorded separately after publication.

Existing installs can update from the idle dashboard. New installations need
the full source/runtime setup described in [LINUX.md](../LINUX.md).
The upgrade ZIP alone is not a first-install image or an operating-system update.

## Public-channel device acceptance

The public 0.6.1 build 10 → 0.8.1 build 17 update was installed on the actual
Switch OLED / Switchroot Ubuntu 24.04.4 ARM64 device. All 80 installed files
match the public package. The install receipt, startup acknowledgment and live
version agree, and the existing registration was retained.

The packaged user timer is enabled and active. After Deckivo closed, its next
natural run completed successfully and reported this build current without a
warning or error. After a full Ubuntu reboot, Wi-Fi autoconnected with KWallet
closed and the timer completed another public-channel check. Gameplay/controller
acceptance remains separate and is not inferred from updater acceptance.
