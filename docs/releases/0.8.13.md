# Deckivo 0.8.13 preview

Android ARM64 build 38 handles an unavailable audio output stream and adjusts the streaming audio buffer. Desktop build 29 prevents held controller input from firing during initial navigation on Apple Silicon Macs. The Switchroot Ubuntu download targets the prepared ARM64 environment.

Install the Android APK over your previous Deckivo installation. Apple Silicon users can use the macOS ZIP. Existing macOS and Switchroot Ubuntu installations can check the signed desktop update feed. New Ubuntu users should follow the installation guide.

The Android APK uses the same signing certificate as the preceding published APK. The macOS bundle has an ad-hoc signature. The release includes corresponding source archives, software bills of materials and SHA-256 checksums. Bluetooth latency and a live PS5 stream were not measured on this build.
