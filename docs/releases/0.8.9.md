# Deckivo 0.8.9 — support audit

Experimental prerelease. Android versionCode 34; macOS and Switchroot Ubuntu build 25.

Patreon is removed from the active registry and Sponsor links. A previously saved Patreon selection falls back to Ko-fi without automatically opening a browser or rewriting preferences. Six methods remain: Ko-fi, Afdian, Boosty, DonationAlerts, DonatePay and OKX Pay. Boosty explicitly requires account verification before accepting payments; Afdian remains unverified. The owner-provided OKX link is an app flow and can open a download page on desktop. Payment receipt, subscriptions and payouts have not been tested.

Current screenshots are captured from the real 0.8.9 Qt UI with empty temporary pairing storage; README/download links and platform labels are refreshed. IDs, the Android signing certificate and RSA desktop update key are unchanged. Old releases are not edited.

Validation: 49 Android release unit tests plus lint/build, 140 desktop tests, 8 support-registry tests, 17 controller-policy checks, 104 Controller Lab states, and 112 rendered website cases plus 16 no-JavaScript pages in each statistics mode. See 0.8.9-validation.json and SHA256SUMS.txt for exact package evidence.

The Mac package remains ad-hoc signed and is not notarized. Physical Switch, PS5 long sessions, controllers and new-user Gatekeeper acceptance remain separate. Donations are optional and do not buy personal support or a delivery deadline.
