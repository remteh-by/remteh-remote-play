# Deckivo 0.8.3 — controller safeguards and audit corrections

Experimental prerelease. Android ARM64 **0.8.3 / 28**; Apple Silicon macOS and
Switchroot Ubuntu ARM64 **0.8.3 / 19**. Existing signing keys, package identities,
registrations and preferences are retained. The previous 0.8.2 release remains
available. Windows, Intel Mac and generic Linux x64 builds are not provided.

## English

- Firmware comparison uses a sanitized JSON version catalog. Deckivo no longer
  downloads or proxies Sony firmware binaries. Installed-version reading stays
  available over supported USB connections; use Sony's official update method.
- Permanent calibration is hidden behind the persistent, default-off **Service
  mode**. A durable backup of the original parameters and an EN/RU warning with
  a mandatory confirmation checkbox precede any permanent write. Temporary
  calibration remains available. No real controller was permanently written.
- English diagnostics cover deep firmware, calibration, audio and export states.
  CI rejects visible Cyrillic in English mode except the Russian language name.
  The other 14 tester languages explicitly use English fallback.
- Unknown funding amounts no longer display a progress bar or unknown-progress
  message. Download counts below 1,000 package downloads are hidden on the home
  page; the data and generated [download history](../DOWNLOADS.md) remain available.
  The threshold is configurable.
- Every language page has one SoftwareApplication and one FAQPage schema. The
  JPEG social cover is 1200 × 630 and uses the actual 0.8.3 b19 desktop interface.
- Ubuntu has a 45-second login check plus hourly checks with up to 10 minutes
  of jitter. Updating Deckivo migrates the installed user timer units.

### Validation and limits

Automated release checks and exact package hashes are recorded in
[the validation receipt](0.8.3-validation.json). Mock Gamepad/HID tests verify UI
states and write gates; they do not certify physical controllers or Bluetooth.

The test Switch was unavailable over ADB and SSH; the PS5 was offline. **Zero
3-minute Android lag runs and zero 30-minute acceptance sessions were measured**
for this release. MediaCodec name, frame counters/drops, decoder latency,
packet loss/FEC, RSSI/band, temperature/throttling and CPU/GPU frequency/load
are **not measured**, not zero. No decoder, debanding or default-profile change
is claimed to fix lag without those measurements. Android #25 → #27 → #28 and
Ubuntu b17 → b18 → b19 hardware transitions remain in the
[owner checklist](../OWNER-CHECKLIST-0.8.3.md). Mac public-update verification is
recorded separately after publication; sustained play is not certified by it.

## Русский

Экспериментальная версия: Android **0.8.3 / 28**, Mac и Ubuntu **0.8.3 / 19**.
Ключи подписи, идентификаторы, регистрация PS5 и настройки сохранены.

- Из Deckivo удалены скачивание и проксирование файлов прошивок Sony. Остались
  чтение установленной версии и сравнение с JSON-каталогом. Для обновления
  геймпада указан официальный способ Sony. Сайт remteh.by не изменялся.
- Постоянная запись скрыта за выключенным по умолчанию «Сервисным режимом».
  До записи обязательны сохранённая исходная копия, предупреждение и галочка
  подтверждения. Временная настройка доступна отдельно. Реальные геймпады
  постоянно не калибровались и не прошивались.
- Дополнен английский перевод глубоких экранов тестера; проверка в CI ловит
  кириллицу. Для остальных 14 языков тестера честно указан английский fallback.
- Без известных сумм не показывается прогресс сбора. Небольшой счётчик
  скачиваний скрыт с главной, история оставлена в документации. Исправлены
  JSON-LD, JPG-превью и актуальность инструкций.
- Ubuntu проверяет обновления через 45 секунд после входа, затем раз в час
  со случайной задержкой до 10 минут; старые timer-unit мигрируют при обновлении.

**Причина торможения Android пока не установлена:** Switch недоступен, PS5
не отвечает. Выполнено **0 трёхминутных замеров и 0 длительных 30-минутных
игровых сессий**. Декодер, кадры/пропуски, задержка, FEC, Wi-Fi и нагрев не
измерены. Исправление торможения и улучшение FPS не заявляются. Проверки на
железе вынесены в чек-лист владельца; результаты сборки и моков их не заменяют.

Донат через [Ko-fi RemTeh](https://ko-fi.com/pavelzayats) остаётся добровольным.
Настройка выплат владельцем и криптоадреса не подтверждены; платежи не выполнялись.
