# Deckivo 0.7.0 — local development preview

This is a compatible feature update after the published 0.6.1 audit fixes.
It has not been published as a tag, release or update feed.

- Genuine PS5, DualSense, DualShock 4 and Xbox Series photographs, with source
  provenance retained. Gallery framing gives equal visible body height without
  distorting proportions; the artificial floor shadow is removed.
- Brand-neutral controller discovery and the bundled RemTeh controller lab:
  measurements, report export and model/transport-specific USB diagnostics.
  Existing deliberate calibration and capability gates remain in place.
- Optional keyboard/mouse gamepad emulation with sensitivity, inversion,
  Escape/focus-loss release and a per-process SDL virtual controller on desktop.
  Android uses its focused relative pointer capture API.
- Additional requested 1080p stream profiles. The current engine does not
  support a 4K Remote Play profile; requested FPS is not measured FPS.
- A private owned Mac engine copy leaves the official installation untouched.
  Normal close stops the network session before Qt teardown, fixing the shutdown
  hang found during this preview's tests.

Mac build 14 is installed locally; Android #26 and the Ubuntu source upgrade
are prepared for later device testing. Ko-fi remains
[RemTeh](https://ko-fi.com/pavelzayats). No payment was conducted.
