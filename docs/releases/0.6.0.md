# Deckivo 0.6.0 · experimental public preview

A new public home for Deckivo: a responsive graphite/lime design, setup guides in
16 languages, visible Ko-fi support, and a public update channel for the native
clients. The project remains based on Chiaki / chiaki-ng / Android Extended.

- **Android:** arm64 APK, versionCode **24**, Android 8+ declared minimum.
- **Mac:** Apple Silicon app **build 9**; requires separately installed official
  chiaki-ng. Ad-hoc signed; **not notarized**.
- **Switchroot Ubuntu:** ARM64 developer source/upgrade **build 9**, Ubuntu 24.04,
  KDE/X11 and matching Switchroot FFmpeg 6.1. The small ZIP upgrades an existing
  runtime; new installations need the complete source and platform guide.
- **Source:** attached complete source archive expands native dependency sources
  and submodules; keep upstream and dependency licenses.

Connected reference PS5 advertises firmware **13.42** (`13420000`); this is not
a claim of support for every firmware.

Install over your existing Deckivo to retain registration. Old private builds
need a one-time migration. Updates do not replace console firmware or the
separate chiaki-ng engine. System security prompts remain under OS control.

**Validation:** 29 Android unit tests; release build and lint pass (249 existing
warnings, zero errors); 28 native tests; 80 website language/viewport cases up to
3840 px with no horizontal overflow or missing images. Physical 0.5.1 updater
transitions were verified on Switch Android, Switch Ubuntu and Mac with data
retained. Earlier local video/audio/GameSir checks remain tied to their actual
builds in the test matrix. This does not certify all 0.6.0 gameplay features.
