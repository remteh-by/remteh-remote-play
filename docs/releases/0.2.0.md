# Deckivo 0.2.0 — локальный кандидат, не опубликован

RemTeh Remote Play теперь называется **Deckivo**. Пакет Android и ключ подписи сохранены; установите APK поверх прежней версии без удаления приложения.

- Developed by [RemTeh.by](https://remteh.by/) и отдельное упоминание Chiaki в разделе «О Deckivo».
- Обновления из GitHub: проверка при открытии, автоматическая загрузка по Wi-Fi и системное подтверждение установки Android.
- Проверки SHA-256, размера, версии, совместимости и подписи APK. Полные соответствующие исходники приложены.
- Новый оригинальный интерфейс, карточки консолей, навигация, настройки, мастер подключения и скрываемые элементы трансляции.
- English по умолчанию, 16 языков, заметный переключатель, режим «Автоматически» по языку системы и RTL для арабского. Ручной выбор сохраняется и имеет приоритет.
- Раздел добровольной поддержки разработки; платёжного провайдера пока нет. Клиентские заявки и платная техподдержка исключены.
- Локальный многоязычный сайт для будущего GitHub Pages.

**Первая установка после 0.1.2:** используйте локальную APK этой сборки и установите поверх старой. Дальнейшие выпуски можно получать из меню «Обновления и о Deckivo».

Android 8+ / arm64-v8a; проверка устройства выполняется на Switch OLED с Android 15. Тестовая сборка — versionCode 12; публикация только после завершённой 1.0.0 и явной проверки владельцем. Это предварительный выпуск: длительная сессия, доступ через интернет и другие устройства отдельно не подтверждены. Проблема чёрного экрана после reconnect остаётся: вернитесь в список консолей и подключитесь заново.

Файлы `validation.json` и, при наличии, `acceptance.json` фиксируют фактически проведённые проверки. Выпуск не обновляет прошивку PS5 или её WebKit.
