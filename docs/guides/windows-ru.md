# Deckivo для Windows 11 x64

Deckivo показывает изображение PlayStation на ПК через домашнюю сеть. В этом руководстве описана предварительная Windows-сборка 0.9.0.5. Для обычной игры после привязки достаточно открыть Deckivo и нажать **Начать игру**.

## Установка и первый запуск

1. Откройте [раздел Releases](https://github.com/remteh-by/remteh-remote-play/releases) и выберите **Deckivo 0.9.0.5 — Windows x64 Preview**. Внизу страницы раскройте **Assets**.
2. Для установки скачайте файл с окончанием **Windows-x64-Setup.exe**. Запустите его от своего пользователя и оставьте включённым пункт создания значка на рабочем столе. Программа также появится в меню «Пуск». Значок Deckivo — зелёная буква D на тёмном фоне.
3. Для переносного запуска скачайте **Windows-x64-Portable.zip**, распакуйте **всю папку** в постоянное место и откройте Deckivo.exe. Чтобы добавить ярлык, нажмите правой кнопкой на Deckivo.exe → «Показать дополнительные параметры» → «Отправить» → «Рабочий стол (создать ярлык)». Во время работы не перемещайте распакованную папку.
4. Если ярлык установленной версии пропал, запустите установщик повторно и выберите создание значка. Папку рабочего стола в Windows может обслуживать OneDrive. Ярлык создаётся на рабочем столе текущего пользователя.

Установщик предварительного выпуска не имеет подписи Authenticode. Для сверки загрузите SHA256SUMS.txt из того же выпуска, выполните в PowerShell команду ниже в папке загрузок и сравните строку SHA-256 с записью для своего файла.

~~~powershell
Get-FileHash .\Deckivo-0.9.0-preview-Windows-x64-Setup.exe -Algorithm SHA256
~~~

## Первая привязка PS5

1. Подключите ПК и PS5 к одной домашней сети. На PS5 войдите в пользователя, от которого будет идти трансляция. Откройте **Настройки → Система → Дистанционная игра** и включите дистанционную игру.
2. В Deckivo откройте **Игровая → Добавить консоль**. Проверьте модель и адрес. Если консоль не обнаружена, посмотрите её IPv4 в настройках сети PS5 и введите в мастер. Нажмите кнопку проверки соединения.
3. Выберите способ получения **Account ID**. Можно войти через PlayStation в браузере или вставить готовый Account ID выбранного профиля в формате Base64. Для совместимой модифицированной PS5 без PSN доступен пункт **Локальный помощник PS5**. Он требует запущенного на самой консоли помощника. [Описание помощника](../../ps5-companion/)
4. Под тем же пользователем PS5 откройте **Настройки → Система → Дистанционная игра → Привязать устройство**. Введите свежий восьмизначный код в поле привязки Deckivo до истечения таймера. Если используете помощник, его собственный код вводится отдельно, на шаге получения Account ID.
5. Дождитесь отметки **Привязана** в «Игровой». Нажмите **Начать игру**. Для следующих сеансов используйте ту же карточку. Сохранённая привязка остаётся в профиле Windows.

## DualSense подключён к самой PS5

1. Для трансляции привяжите к Deckivo второй пользовательский профиль PS5.
2. Запустите трансляцию через этот профиль. Нажмите **PS** на DualSense, который уже связан с консолью, и выберите свой основной игровой профиль. Такой порядок позволяет играть с консольного геймпада и смотреть изображение на ПК.
3. В Deckivo сообщение «К ПК геймпад не подключён» относится только к устройствам Windows. При таком способе подключения оно ожидаемо.
4. Если поверх игры виден статус Remote Play, включите на PS5 **Скрыть статус подключения к дистанционной игре** в разделе дистанционной игры, если эта настройка доступна в вашей версии ПО. Проверяйте результат в самой игре. Главное меню PS5 может показывать статус.

## Изображение, управление и завершение

- В **Игровая → Профиль трансляции** выберите **Чёткий · 1080p / 60** для качественной локальной сети. В **Настройки** выберите режим **Весь экран**. На мониторе 2560×1440 клиент масштабирует видеопоток 1920×1080. При рывках попробуйте проводное подключение или профиль 720p.
- Для игры через ПК подключите геймпад к Windows и откройте **Контроллер → Проверить контроллер**. В Controller Lab нажмите кнопку геймпада и проверьте стики и курки. Диагностика и вибрация зависят от поддержки устройства и браузера.
- В потоке **F8** включает управление мышью, **Esc** освобождает курсор. WASD управляет левым стиком. Чувствительность, инверсию и назначения кнопок мыши можно менять в приложении. Экранный геймпад включается отдельно и по умолчанию скрыт.
- Во время трансляции **Ctrl+O** открывает меню сеанса. Для завершения выберите отключение сессии. Перевод PS5 в режим покоя выбирайте только тогда, когда хотите усыпить консоль.
- В **Сеансы** доступны история, длительность и число декодированных кадров. Здесь можно выключить запись истории, очистить её или экспортировать отчёт.

## Если что-то не работает

| Что видно | Что проверить |
| --- | --- |
| Консоль отсутствует в списке | Проверьте питание, общую локальную сеть и адрес PS5. Попробуйте ввести адрес вручную. |
| Код отклонён или закончился таймер | Откройте «Привязать устройство» заново в нужном профиле и используйте новый код. Убедитесь, что Account ID относится к этому же пользователю. |
| PS5 в режиме покоя | Для пробуждения по сети включите на PS5 в параметрах энергосбережения сохранение подключения к интернету и включение PS5 по сети. Нажмите «Начать игру». |
| Окно открылось, но изображения нет | Дождитесь результата подключения. Проверьте состояние PS5, локальную сеть и маршрут при включённом VPN. Успешная проверка TCP подтверждает доступность сервиса, для видео также нужен обмен UDP. При сохранённой привязке сначала повторите запуск с карточки консоли. |
| Не видно доступного обновления | Для этой предварительной Windows-версии новые пакеты скачиваются вручную со страницы Releases. |
