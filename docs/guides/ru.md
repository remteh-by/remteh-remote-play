## Перед началом

Deckivo 0.8.3 — экспериментальный открытый клиент Remote Play для PS5. Начните в одной домашней сети. На PS5 войдите в нужный профиль: Настройки → Система → Дистанционное воспроизведение → Включить дистанционное воспроизведение. При первой привязке консоль должна быть включена. Предпочтительна сеть 5 ГГц; гостевая сеть может запрещать связь устройств. Deckivo не устанавливает Android/Linux и не меняет прошивку PS5.

## Android

### Первая установка

1. Скачайте APK arm64 по ссылке ниже; требуется Android 8 или новее. Установите APK и разрешите установку только выбранному источнику, когда появится запрос. Не отключайте Play Защиту.
2. Откройте Deckivo, выберите язык и привяжите нужный профиль PS5. Совместимый геймпад подключите в настройках Bluetooth Android.

### Обновление

1. Оставьте автообновления включёнными. Разрешите Deckivo установку из этого источника и подтвердите системный установщик. Android может требовать подтверждение каждой установки.
2. При ручном обновлении установите APK с прежней подписью поверх Deckivo. Не удаляйте приложение и не очищайте хранилище: привязка, язык и настройки сохранятся.

### Удаление

1. Завершите трансляцию. Откройте Настройки Android → Приложения → Deckivo → Удалить. Приложение, его привязка, настройки и история на этом устройстве будут удалены.
2. APK и отчёты, сохранённые в «Загрузках», остаются — удалите их отдельно при необходимости. Игры и сохранения PS5 не затрагиваются. После новой установки потребуется привязка.

## macOS

### Первая установка

1. Используйте Mac с Apple Silicon и macOS 13 или новее. Отдельно установите официальный chiaki-ng, привяжите в нём PS5 и закройте трансляцию.
2. Распакуйте Mac ZIP и перенесите Deckivo.app в ~/Applications. Сборка подписана ad-hoc, но не прошла нотаризацию. Если после попытки запуска macOS требует подтверждение, используйте «Всё равно открыть» для этого приложения в Системных настройках → Конфиденциальность и безопасность. Не отключайте Gatekeeper целиком.
3. В настройках Deckivo импортируйте регистрацию из chiaki-ng и выберите адрес консоли. Сохраните chiaki-ng: его движок нужен для трансляции.

### Обновление

1. Оставьте автообновления включёнными. Установка ждёт завершения трансляции; привязка и настройки остаются в ~/Library/Application Support/Deckivo/private.
2. Для ручного обновления закройте Deckivo и замените только Deckivo.app распакованным приложением. Не удаляйте папку данных и chiaki-ng.

### Удаление

1. Закройте Deckivo и переместите Deckivo.app из ~/Applications или выбранной вами папки в Корзину. chiaki-ng и данные Deckivo при этом остаются.
2. Если нужно удалить также привязку, настройки, историю и загруженные обновления, отдельно удалите ~/Library/Application Support/Deckivo через Finder, предварительно сохранив нужное. В папке есть закрытые ключи привязки — не передавайте её другим.
3. chiaki-ng — отдельное приложение со своими данными; при необходимости удалите его отдельно. Игры и сохранения на PS5 остаются.

## Switchroot Ubuntu

### Первая установка

1. Используйте поддерживаемую Switchroot Ubuntu 24.04 ARM64 со штатными драйверами. Установите зависимости из docs/LINUX.md, скачайте и распакуйте полный архив исходников. Маленького ZIP обновления для первой установки недостаточно.
2. В корне исходников выполните python3 desktop/linux/build-install.py, затем python3 desktop/linux/pair.py. Следуйте приватным запросам привязки и запустите Deckivo из меню приложений. Не заменяйте драйверы NVIDIA/FFmpeg Switchroot.

### Обновление

1. Оставьте автообновления включёнными. Пользовательский таймер скачивает подписанный пакет, приложение устанавливает его вне трансляции. Привязка и настройки сохраняются.
2. Для ручного восстановления распакуйте Linux ZIP обновления и выполните python3 desktop/linux/upgrade.py из его корня. Требуется уже установленный runtime.

### Удаление

1. Закройте Deckivo. Сначала выключите таймеры и удалите их unit-файлы командами ниже, затем удаляйте программу.
2. Удалите ~/.local/bin/deckivo, ~/.local/share/applications/Deckivo.desktop и ярлык Deckivo.desktop с рабочего стола. Удаление ~/.local/share/deckivo также удаляет runtime и Linux-файл registration.json. Если привязка нужна, предварительно сохраните этот приватный файл.
3. Настройки, кэш обновлений и история в ~/.config/deckivo остаются до отдельного удаления. Сохраните их при необходимости; они могут содержать ключи. Игры и сохранения PS5 не затрагиваются.

```sh
systemctl --user disable --now deckivo-update.timer deckivo-update-login.timer
systemctl --user stop deckivo-update.service
rm -f ~/.config/systemd/user/deckivo-update.timer ~/.config/systemd/user/deckivo-update-login.timer ~/.config/systemd/user/deckivo-update.service
systemctl --user daemon-reload
```

```sh
# Initial runtime (complete source kit)
python3 desktop/linux/build-install.py
# Interactive pairing
python3 desktop/linux/pair.py
# Upgrade an existing runtime only
python3 desktop/linux/upgrade.py
```

## Привязка и первое подключение

Нужен Account ID именно выбранного профиля PS5 в формате Base64, а не ник или почта. Android принимает его в мастере. Необязательный локальный ELF-помощник может прочитать ID на уже подготовленной для запуска ELF консоли; обычному Remote Play он не нужен. На PS5 откройте Настройки → Система → Дистанционное воспроизведение → Привязать устройство и введите свежий восьмизначный код до истечения таймера. Код помощника и код Remote Play разные. Linux-скрипт запрашивает данные интерактивно, Mac импортирует вашу регистрацию chiaki-ng. Не публикуйте PIN, ключи и файлы регистрации.

## Управление и качество

Начните с 720p. При нестабильном Wi-Fi снизьте битрейт или выберите 30 FPS. Это запрошенные параметры, а не обещание измеренного FPS. GameSir G8+ проверяли на Android в синем режиме и на Ubuntu с адаптером управления. На Android короткий свайп вверх от нижнего края показывает скрываемые PS/Touch. На Linux Home соответствует PS, Capture — нажатию тачпада; сочетание +/− для отключения можно выключить. Проверьте стики, курки, кнопки и звук на своём устройстве. Перед выходом сохраните игру: отключение трансляции не закрывает игру.

## Автообновление

Сохраняйте пакет и ключ подписи: обновляйте поверх старого приложения. Android проверяет GitHub при открытом главном экране/экране обновлений обычно раз в шесть часов и скачивает по Wi-Fi без лимита трафика. Android 12+ может установить собственное обновление после разрешения источнику, но вправе запросить подтверждение. Mac/Linux проверяют подпись метаданных и хеш, ждут завершения трансляции и перезапускают приложение. Спящее устройство и закрытое приложение не обеспечивают постоянную фоновую проверку. Старые частные сборки требуют однократного перехода; подробности — в инструкции обновлений.

## Ошибки и ограничения

При ошибке привязки проверьте профиль, Account ID, свежий код, IP и изоляцию Wi-Fi. При чёрном экране завершите трансляцию, закройте другие клиенты Remote Play и подключитесь заново, попробуйте меньшее качество. При ошибке обновления установите пакет выпуска поверх существующей установки, сохранив данные. Точные устройства и версии — в таблице ниже. Интернет/VPN, пробуждение, все функции геймпадов и длительные сеансы ещё не сертифицированы. Windows, Intel Mac и Linux x64 запланированы. Зависание WebKit относится к PS5 и не исправляется клиентом.
