# Deckivo 0.6.0 public presentation

Three accepted image concepts cover the hero, the text-led setup/test sections,
and support/footer. Static HTML, CSS and local fonts implement the design.

- Graphite `#101216`, surface `#1a1e24`, text `#f3f5f7`, muted `#a4acba`, lime
  `#daf975`, lavender `#aaa0f5`; thin neutral dividers.
- Bundled IBM Plex Sans under OFL, medium-weight headings and restrained labels.
- Adaptive full-width layout with `clamp()` gutters. Verify 1920, 2560 and
  3840 px, mobile and Arabic RTL. No fixed 1200 px desktop column.
- Lime primary actions and outlined secondary actions; visible keyboard focus,
  skip link and reduced-motion support.
- Hero: left headline/actions, right proportional original PS5 photo, lavender
  orbit. No pretitle. Text-only download rows, setup columns and factual table.
- Support: oversized title, original product photo, voluntary Ko-fi action.
  Footer links all 16 guides and preserves upstream/image credits.

The site labels 0.6.0 experimental and separates earlier gameplay from exact
updater tests. No untested Windows/Intel/x64 downloads or Internet-play promises.
Ko-fi uses `https://ko-fi.com/pavelzayats` without individual support promises.
No analytics, tracking cookies or pairing data are collected by this website.
