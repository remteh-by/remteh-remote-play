# Public presentation review · 0.6.0

The implementation was compared with the accepted hero, setup and support
concepts in the built-in browser. The original product image, not a fictional
console rendering, is the delivered asset.

| Comparison point | Result |
|---|---|
| Graphite background, lime primary action, lavender orbit | Matched; quiet divider treatment retained |
| Two-line headline and right-hand proportional PS5 | Matched; product enlarged in final alignment pass |
| Generous primary action and restrained guide link | Matched; duplicate English guide text fixed |
| Open download rows / three setup steps / versioned evidence table | Matched; no repeated image in middle sections |
| Oversized support title, product and voluntary Ko-fi | Matched; no individual-support promise |
| Canonical app identity | Uses the actual current lime Deckivo icon, rather than the generated approximation |
| Required copy | Real platforms/builds, prerequisites and limits; no invented benchmarks |
| Wide and mobile layouts | 80 language/viewport combinations, 390/768/1920/2560/3840 px, no page overflow or missing images |

The first tablet pass exposed Russian/Ukrainian header overflow. The header now
places navigation on a second row at tablet widths. Final browser checks also
covered Arabic RTL, visible guide language links and the Ko-fi destination.
English remains the first-visit default; Auto follows the browser language.
Technical evidence/download notes are English outside English/Russian, with
full localized setup guides available in all 16 languages.

The GitHub cover is an actual screenshot of the implemented public landing page.
Private device screenshots and raw logs are not published. No analytics or
third-party script/CDN is required for rendering the site.
