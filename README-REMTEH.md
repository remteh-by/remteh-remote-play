# Deckivo 0.8.3 · Русская инструкция

[Подробная установка](https://github.com/remteh-by/remteh-remote-play/blob/v0.8.3/docs/guides/ru.md) · [Скачать 0.8.3 preview](https://github.com/remteh-by/remteh-remote-play/releases/tag/v0.8.3) · [Сайт](https://remteh-by.github.io/remteh-remote-play/ru/)

Deckivo передаёт изображение PS5 на другое устройство. Устанавливайте клиент на Android, Mac или подготовленную Switchroot Ubuntu; на PS5 включите дистанционное воспроизведение.

- Android ARM64: APK 0.8.3, build 28, Android 8+.
- Mac Apple Silicon: 0.8.3 build 19, macOS 13+, отдельный chiaki-ng.
- Switchroot Ubuntu ARM64: 0.8.3 build 19. Маленький Linux ZIP обновляет существующий runtime. Для первой установки нужен полный архив исходников, папка source/ и Linux guide.

Обновляйте поверх существующей программы. Сохранённая PS5 и регистрация должны остаться. Физическая приёмка каждой версии записана в [таблице испытаний](https://github.com/remteh-by/remteh-remote-play/blob/v0.8.3/docs/TESTED.md).

В обычной диагностике постоянная запись скрыта. Сервисный режим сохраняется локально; перед постоянной записью нужны резервная копия и отдельное подтверждение. Прошивки контроллеров обновляются официальным способом Sony, бинарные файлы Deckivo не раздаёт.
