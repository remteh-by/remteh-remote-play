# Deckivo 0.9.0.4 — Windows x64 Preview

## Русский

Первый предварительный выпуск для Windows 11 x64. Установщик создаёт ярлык на рабочем столе текущего пользователя. Приложение, установщик и ярлыки используют официальный знак Deckivo. Доступны локальная привязка PS5, пять профилей качества, полноэкранный просмотр, настройка мыши, экранный геймпад, Controller Lab и история сеансов.

Скачайте **Deckivo-0.9.0-preview-Windows-x64-Setup.exe** для установки или распакуйте **Deckivo-0.9.0-preview-Windows-x64-Portable.zip** целиком и запустите Deckivo.exe. Хеши обеих загрузок приведены в **SHA256SUMS.txt**.

## English

Experimental Windows 11 x64 build. Run the Setup executable, or extract the entire Portable ZIP and launch Deckivo.exe. The installer creates a desktop shortcut by default. Both packages and the executable use Deckivo's official icon. Pair your PS5 in **Home → Add console**. Select a local video preset and **Start playing**.

Tested on Windows 11: installer, desktop shortcut, retained pairing, local session history, control mapping and simulated multitouch. A local PS5 delivered 1080p video scaled to a 2560×1440 fullscreen display during testing of the Windows port. A Windows-attached physical controller, haptics and a 30-minute endurance session have not been verified for this build. Downloads are manual. This preview has no Authenticode signature. The Windows release does not change the Android, macOS or Linux update feeds.
