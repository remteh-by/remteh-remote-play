# Deckivo 0.9.0.5 — Windows x64 Preview

Скачайте **Deckivo-0.9.0-preview-Windows-x64-Setup.exe** для установки в своём профиле Windows 11 x64. Чтобы запустить без установки, распакуйте **Deckivo-0.9.0-preview-Windows-x64-Portable.zip** целиком. Контрольные суммы обеих загрузок приведены в **SHA256SUMS.txt**.

Номер сборки 0.9.0.5 отображается в сведениях приложения и установщика. Обновление поверх предыдущей версии использует тот же идентификатор приложения. Обновления Windows устанавливаются вручную. Подпись Authenticode отсутствует. Для этой сборки игровая сессия с физической PS5 не проверялась.

## English

Install the Setup executable or extract the complete portable ZIP and launch Deckivo.exe. The installer, executable and application metadata identify build 0.9.0.5. The Windows preview uses manual updates. The packages are unsigned. Refer to the SHA256SUMS file to verify a download.
